KTX 매진 열차,
빈자리 나면 알아서 잡아드려요

내 PC에서 돌아가는 개인용 프로그램이에요. 빈자리가 생기면 자동으로 예약하고, 디스코드 채널로 알려줘요.

Windows용 다운로드 (ktx.exe)

시작하는 방법

  1. ktx.exe를 실행해요. 잠시 뒤 브라우저가 열려요(별도 창은 안 떠요). 윈도우 보안 경고가 뜨면 추가 정보 → 실행을 눌러요.
  2. 코레일 계정을 입력해요. 비밀번호는 내 PC의 Windows 자격 증명 관리자에만 저장돼요.
  3. 안내해 준 사람에게 받은 디스코드 웹후크 URL을 붙여 넣어요. 확인 메시지가 디스코드 채널에 오면 연결된 거예요.
  4. 노선·날짜·시간대를 고르고 감시 시작을 눌러요. 빈자리가 나면 디스코드로 알림이 와요.
  5. 알림을 받으면 10분 안에 코레일톡에서 결제해요. 결제는 자동으로 하지 않아요.

꼭 알아두세요

  1. 감시는 PC가 켜져 있고 프로그램이 켜져 있는 동안만 돼요. 브라우저 탭을 닫아도 계속 돌고, 끄려면 작업 표시줄 시계 옆 KTX 아이콘 → 종료를 눌러요. 절전·최대 절전은 꺼 두세요. (화면 잠금은 괜찮아요.)
  2. VPN을 끄고 일반 회사·집 네트워크에서 실행해야 해요. 코레일이 VPN·서버 IP를 막아요.
  3. 조회 간격은 기본 30초예요(30초 · 1분 · 5분 · 10분 또는 직접 입력, 최소 10초). 너무 짧게 하면 계정이 제한될 수 있어요.
개인 사용 전용이에요. 비공식 방식이라 코레일 앱 업데이트로 언제든 동작이 멈출 수 있고, 사용에 따른 책임은 사용자에게 있어요.
