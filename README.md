# KTX 자동예매

KTX 매진 열차를 감시하다가 자리가 나면 **자동 예약**하고 **디스코드**로 알려주는 개인용 프로그램.
각자 **자기 PC**에서 실행하고, 코레일 계정은 각자 본인 것을 씁니다. 알림은 디스코드 채널로 받으므로 여러 명이 같은 채널을 같이 봐도 됩니다.
결제는 자동화하지 않습니다 — 알림을 받고 코레일톡에서 기한(약 10분) 안에 직접 결제하세요.
코레일톡 **홈 → 전체 메뉴 → 아래쪽 [기차] → 예약 승차권 조회·취소**에 들어가면 결제할 수 있습니다.
결제를 마치면 코레일 발권 내역에서 같은 예약번호의 승차권을 찾아 카드를 **예약 완료**(열차·좌석·금액)로 바꾸고 디스코드로도 알립니다.
기한이 지나도록 발권 내역에 없으면 만료로 보고 같은 조건으로 감시를 최대 2번 자동으로 다시 시작합니다. 결제 여부를 확인하지 못하면 다시 잡지 않습니다.

- 클라이언트: [pykorail](https://pypi.org/project/pykorail) (비공식, 코레일톡 API)
- 서버: FastAPI(내 PC `localhost`에서만 열림) + 백그라운드 감시 스레드
- 알림: 디스코드 웹후크 (채널 하나에 웹후크 URL 하나)
- 비밀번호/웹후크 URL: Windows 자격 증명 관리자(keyring)에 저장

## 사용 (exe)

[Releases](../../releases/latest)에서 `ktx.exe`를 받아 실행 → 브라우저에서 첫 실행 마법사를 따라가면 됩니다.
콘솔 창 없이 트레이 아이콘(작업 표시줄 시계 옆)으로 돌고, 거기서 **열기 / 종료**를 할 수 있습니다. 로그는 `%APPDATA%\ktx-macro\ktx.log` (예약·로그인 같은 이력 포함, 최대 약 4MB까지만 보관).
새 버전이 나오면 화면 위에 안내가 뜨고 **지금 업데이트** 버튼 한 번으로 바꿀 수 있어요(설정 → 업데이트의 `지금 확인`으로 바로 확인도 가능). 하루 한 번 이 저장소의 GitHub 릴리스만 조회해요(`KTX_NO_UPDATE_CHECK=1`로 끔).
- 버튼을 누르면 릴리스의 `ktx.exe`를 받아 GitHub가 알려 주는 SHA256·크기와 대조하고, 맞을 때만 실행 중인 exe와 바꿔 다시 시작해요(약 10초, 설정과 감시 목록은 그대로 이어집니다). 해시가 없거나 주소·크기가 이상하면 설치하지 않고 `직접 받기`만 보여요.
- 결제 대기 중인 예약이 있으면 재시작하는 동안 결제 알림이 끊기므로 업데이트를 막아요. 개발 실행(`uv run`)에서는 쓸 수 없어요.
- 교체 뒤 첫 실행에서 옛 exe(`ktx.old`)를 지워요. 새 exe가 뜨지 못하면 `ktx.old`가 남아 있으니 이름을 `ktx.exe`로 되돌리면 복구돼요.
안내 페이지: GitHub Pages (`docs/`).

## 개발

```bash
uv sync
uv run python run.py      # http://localhost:8000 — 계정/키는 웹 UI 첫 실행 마법사에서 입력
uv run pyinstaller ktx.spec   # dist/ktx.exe

# E2E 테스트 (실제 브라우저 + 실제 코레일 로그인, 별도 포트/저장소 사용)
KTX_TEST_KORAIL_ID=... KTX_TEST_KORAIL_PW=... uv run pytest tests/test_e2e.py -v
```

계정과 웹후크 URL은 `.env`가 아니라 Windows 자격 증명 관리자(keyring, 서비스명 `ktx-macro`)에만 저장됩니다.

릴리스: `git tag v1.0.1 && git push --tags` → GitHub Actions가 exe를 빌드해 Releases에 올립니다.
Pages: `main` 푸시마다 `docs/`가 자동 배포됩니다 (워크플로가 Pages를 직접 켭니다). 주소: <https://jaychoi07.github.io/ktx/>

## 디스코드 준비 (채널 만드는 사람이 1회)

1. 디스코드 서버에 알림을 받을 채널을 만듭니다.
2. 채널 설정 → **연동** → **웹후크** → 새 웹후크 → **웹후크 URL 복사**
3. ktx 첫 실행 마법사(또는 설정 → 디스코드 알림)에 URL을 붙여 넣습니다. 채널에 확인 메시지가 오면 완료입니다.
4. 가족 등 다른 사람과 같이 쓰려면 서버에 초대하고, 각자 PC의 ktx에 **같은 URL**을 넣으면 됩니다. 메시지 머리에 코레일 계정 이름이 붙어 누구 예약인지 구분됩니다.
5. **예약 성공**만 `@everyone`으로 알려서 폰 푸시가 울립니다(나머지 알림은 멘션 없이 전송). 폰 디스코드 앱에서 서버 알림의 `@everyone과 @here 알림 억제`를 꺼 두고 채널을 음소거하지 마세요.

> 웹후크 URL을 아는 사람은 누구나 그 채널에 글을 올릴 수 있습니다. **저장소에 넣지 말고** 사용할 사람에게만 따로 전달하세요. 유출되면 연동 화면에서 웹후크를 지우고 새로 만드세요.

## 주의

- 조회 간격 기본 30초(프리셋 30초/1분/5분/10분 또는 직접 입력, 최소 10초, ±지터). 더 짧게 하면 계정/IP 제한 위험이 있습니다.
- 이용제한 감지 시 10분간 자동 중단하고 디스코드로 알립니다 (첫 알림만 `@everyone`, 계속 막혀 있으면 1시간마다 멘션 없이 한 번). 멈춘 동안에도 결제 재알림은 결제기한까지 계속 갑니다.
- 감시 시간대의 끝까지 열차를 조회합니다(쪽당 약 10편, 최대 10쪽). 시간대가 넓을수록 한 번에 나가는 요청이 늘어요.
- **VPN/클라우드 IP에서는 코레일이 차단**합니다. 일반 가정·회사 네트워크에서 실행하세요.
- 개인 사용 전용입니다. 되팔기·상업적 이용 금지. 약관 위반 소지와 책임은 사용자에게 있습니다.
- 비공식 API라 코레일 앱 업데이트 시 언제든 동작이 깨질 수 있습니다.
- `.env`, `data/` 는 절대 커밋하지 마세요 (`.gitignore` 처리됨).
